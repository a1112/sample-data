# Sample Data

Private sample-data registry for development, integration testing, and reproducible validation across projects.

Large datasets are stored under a project namespace. Every imported dataset must include provenance, a versioned manifest, file counts, byte totals, and integrity metadata. Production credentials, secrets, and unapproved customer data must not be committed.
